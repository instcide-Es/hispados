# Código de conducta

Hispa-DOS es un proyecto para que cualquiera pueda revivir un ordenador viejo y aprender cómo funciona por dentro. Queremos que colaborar aquí sea agradable para todo el mundo, sepa mucho o poco.

## Lo que esperamos

- Trato amable y respetuoso, también cuando no estamos de acuerdo.
- Paciencia con quien empieza: todos hemos preguntado alguna vez qué es una interrupción.
- Críticas al código, nunca a las personas.
- Reconocer el trabajo de los demás y decir de dónde viene cada idea.

## Lo que no aceptamos

- Insultos, burlas o comentarios despectivos por el origen, el sexo, la identidad, la edad, la discapacidad, la religión, el nivel de conocimientos o cualquier otro motivo.
- Acoso, en público o en privado, y publicar datos personales de otros.
- Mensajes de propaganda o *spam*.

## Qué pasa si alguien no lo cumple

Quien mantiene el proyecto puede editar o borrar comentarios, cerrar conversaciones y, si hace falta, bloquear a quien no respete estas normas. Si algo te incomoda, avisa abriendo una *issue* o, si prefieres que no sea público, con un mensaje privado a quien mantiene el proyecto en GitHub ([@instcide-Es](https://github.com/instcide-Es)).

Inspirado en el [Contributor Covenant](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).
